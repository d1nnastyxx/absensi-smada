1. download termux
2. download kesiswaan-smada.zip
3. install termux
4. ekstrak kesiswaan-smada.zip ke internal
5. buka termux
6. ketik command berikut:
   a. apt update -y
   b. apt upgrade -y
      (kalau ada konfirmasi ketik Y terus enter)
   c. apt install git -y
   d. apt install nodejs -y
   e. termux-setup-storage
      (kalau ada minta izinin buat file nanti izinin aja biar bisa baca storage)
   f. cd /sdcard
   g. cd kesiswaan-smada
   h. npm install
   j. node server.js
7. buka browser (terserah bisa chrome, edge, brave, dll)
8. ketik aja localhost:3000
9. selesai


NOTE: untuk ubah variabel lain misal kaya password admin bisa di file .env.local bagian ADMIN_PASS
